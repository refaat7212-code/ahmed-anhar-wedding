# دعوة زفاف — بشمهندس أحمد & دكتورة أنهار

التاريخ: 26 سبتمبر 2026
الوقت: 5:00 مساءً
المكان: قاعة Grand View
الخريطة: https://maps.app.goo.gl/YWbdsp6diNrH9PyYA

## التشغيل
افتح `index.html` مباشرة في المتصفح.

## الرفع على Vercel
ارفع الملفات الثلاثة:
- index.html
- style.css
- script.js

ثم اختر المشروع كـ static site.

## تعديل الصور
استبدل عناصر `.placeholder` في `index.html` بعناصر `<img>`، مثل:
`<img src="images/photo1.jpg" alt="أحمد وأنهار">`

## الموسيقى
لم أضمّن ملفًا موسيقيًا لأنك لم ترسل ملفًا تملكه/تملك حق استخدامه. يمكن إضافة ملفك المحلي لاحقًا.
